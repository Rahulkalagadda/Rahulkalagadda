- 🧠 **CAP — Cognitive Assessment Platform**: a clinical-grade digital neuropsychological assessment tool for the Indian clinical market. 22+ cognitive tasks, validated screeners (PHQ-9, GAD-7, ASRS v1.1), and sub-2-second automated PDF reporting, built alongside a clinical collaborator who signs off on every scoring and taxonomy decision.
